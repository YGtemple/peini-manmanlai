# 陪你慢慢来 · 一个不打鸡血的成长站

> 一句话简介：纯静态多页中文成长站，专注 / 习惯 / 心态 / 故事 / 金句五个频道，零依赖、零构建、离线可读。

## 一、这是什么

一个 7 个页面的中文成长主题静态站。它的立场写在首页第一句：

> 不喊你加油，只陪你慢慢来。

和常见的成功学站点不同，这里不卖焦虑、不打鸡血、不喊「你必须成功」，也不推荐任何付费产品。内容定位是**反内耗、温和坚持、确定性陪伴**三件事：可落地的专注与习惯方法、情绪稳定的心态支持、真实普通人的成长故事，以及可收藏的金句。

## 二、五个频道

| 页面 | 频道 | 内容 |
|---|---|---|
| `index.html` | 首页 | 站点主张与四个频道入口 |
| `focus.html` | 专注 | 从 2 分钟起步把注意力捡回来的方法 |
| `habits.html` | 习惯养成 | 三条温和坚持的方法，长期主义时间线 |
| `mindset.html` | 心态管理 | 反内耗、戒玻璃心、减少自我关注 |
| `stories.html` | 成长故事 | 四类普通人真实故事，数字照录公开报道 |
| `quotes.html` | 金句库 | 可筛选、可搜索、可复制的金句卡片 |
| `resources.html` | 关于·资源 | 立场说明、15 个内容来源平台清单、取证与数据说明 |

## 三、设计与实现

### 视觉

一套暖色纸感体系，全部由 CSS 变量定义在 `:root`：

```css
--bg:      #f5efe4;   /* 暖雾米白 / 燕麦 */
--ink:     #463b30;   /* 暖棕正文 */
--accent:  #c08a3e;   /* 低饱和琥珀 */
--navy:    #20293a;   /* 金句库暗皮肤 */
```

标题用宋体系（`Songti SC` / `Noto Serif SC`），正文用苹方系（`PingFang SC` / `Microsoft YaHei`）。图标不用图标库——全部是内联 SVG data URI，连 favicon 都是一个 data URI（圆底一个「慢」字）。

### 三个值得一提的交互

**金句库的双皮肤**：`quotes.js` 支持米底 / 暗底切换，选择写进 `localStorage`，下次进来还是上次的皮肤。

**金句库的双重筛选**：标签筛选 + 关键词搜索可以叠加，另外还有两个精选开关——`data-hook`（适合做开场钩子）和 `data-close`（适合做结尾升华），这对应的是短视频创作里找台词的场景。

**频道页互链预筛**：金句库支持 `?tag=xx` 查询参数，其他频道页可以直接链到某个标签下的金句集合。

故事页有按分类筛选（健身逆袭 / 草根重活一次 / 读书学习陪伴 / 康复里程碑）。

### 内容溯源的处理方式

这是我认为比较重要的一点。站里引用的金句和故事**没有来源不明的**——每一条都标了出处（微博、知乎、抖音、小红书、小宇宙等具体平台与账号），且都带可点击的原文链接。`resources.html` 里还专门列了 15 个来源平台的内容气质速写，以及透明的取证与数据说明。

刻意避开的：不编造数据、不匿名化来源、不把别人的话写成自己的。

## 五、特点

- **零依赖、零构建**：没有 npm、没有框架、没有 CDN 外链、没有字体请求。双击 `index.html` 就能打开，断网也能完整阅读。
- **完全离线可读**：所有样式和脚本都是本地文件，图标是内联 SVG data URI，连 favicon 都不走网络。
- **不收集任何数据**：没有统计代码、没有第三方脚本、没有 cookie。`localStorage` 只用来记金句库的皮肤偏好，不外传。
- **单一样式表**：7 个页面共用一份 `style.css`，改一个变量全站换肤。
- **可移植**：整个文件夹拷到任何静态托管（GitHub Pages、Vercel、对象存储）即可直接发布，无需配置。
