# peini-manmanlai

一个关于慢慢长大的静态站点——陪伴、耐心与长期练习。

<sub>HTML · 静态</sub>

---

## 是什么

一个围绕单一想法搭的小站：有些事值得慢慢做。页面承载短随笔和实际笔记，而不是信息流。

## 目录

```
index.html      站点
assets/         样式与图片
```

## 运行

用浏览器打开 `index.html`，或起一个本地服务：

```bash
python -m http.server
```
